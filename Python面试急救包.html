1. 开场怎么描述你的 Python 水平这段话先背下来，能救你一半的场

如果他说「你 Python 什么水平？」
「我属于实用型：能读写脚本、能调大模型 API、能用 pandas 处理表格数据、能看懂并修改现成代码；算法和复杂后端架构不是我的强项。这个岗位如果需要写脚本、对接接口、处理客户数据，我是能干活的；遇到没见过的库，给我文档我能上手。」
为什么这样说：既给出能力范围，又给了「不会但能学」的预期。面试官最怕的是吹「精通」然后一问就露馅。
禁忌回答：「精通 Python」/「什么都能写」/「我零基础但学得快」。前两个会被当场验证，最后一个等于自曝没有交付能力。

2. 12 个必会基础按被问概率排序，每题都有「30 秒答案」

01list、tuple、dict 有什么区别？高频
「list 是列表，有序、可以改；tuple 是元组，有序但不能改；dict 是键值对，用 key 取值，查找快。实际干活最常用 dict 存结构化数据，比如接口返回的 JSON。」 
# list
nums = [3, 1, 2]
nums.append(4)          # [3,1,2,4]
nums[0]                 # 3

# dict
user = {"name": "张三", "age": 20}
user["age"] = 21
user.get("phone", "无")  # 不存在的 key 不报错
for k, v in user.items():
    print(k, v)
02列表推导式是什么？高频
「就是把一个 for 循环加筛选，写成一行。比如把列表里的正数取出来平方。」 
nums = [1, -2, 3, -4]
pos = [x for x in nums if x > 0]      # [1, 3]
sq  = [x * x for x in nums]          # [1, 4, 9, 16]
names = [u["name"] for u in users if u["active"]]
必须会。这是 Python 最有辨识度的写法，会写这一句，面试官立刻觉得你「真用过」。
03字符串常用操作有哪些？
「用得最多的是切分、拼接、去空格、替换和格式化输出。」 
s = "  a,b,c  "
s.strip()                  # 'a,b,c' 去首尾空白
s.strip().split(",")       # ['a','b','c']
"-".join(["a", "b"])       # 'a-b'
s.replace("a", "x")
# f-string 最常用
name, score = "张三", 92
print(f"{name} 考了 {score} 分")
04函数默认参数的坑（可变对象）高频坑
「默认参数只在函数定义时创建一次，所以如果默认值是 list 或 dict，多次调用会共享同一个对象，越加越多。正确做法是默认写 None，在函数里再判断。」 
# 错误写法
def add(item, box=[]):
    box.append(item)
    return box
add(1)   # [1]
add(2)   # [1, 2] ← 坑！共享了

# 正确写法
def add(item, box=None):
    if box is None:
        box = []
    box.append(item)
    return box
这题几乎是最经典的 Python 面试题，答案就一句：默认参数在定义时求值，可变对象会被共享。
05赋值、浅拷贝、深拷贝的区别
「等号是引用，两个变量指向同一个对象；浅拷贝只复制外层，里面嵌套的还是共享；深拷贝是完全独立的一份。」 
import copy
a = [[1, 2], [3, 4]]
b = a                  # 引用
c = copy.copy(a)       # 浅拷贝：外层独立，内层共享
d = copy.deepcopy(a)   # 深拷贝：完全独立

b.append([9])          # a 也变
c[0].append(99)        # a[0] 也变！
d[0].append(88)        # a 不变
06try / except 怎么用？
「把可能出错的代码放 try 里，出错就进 except 处理，finally 不管成不成功都会执行，一般用来关资源。调接口、解析数据我都会包一层。」 
try:
    n = int(input_str)
except ValueError:
    print("不是数字")
except Exception as e:
    print("其他错误:", e)
finally:
    print("无论如何都执行")
07怎么读写文件？
「用 with open，它会自动关文件。读用 r，写用 w，追加用 a，中文记得加 encoding='utf-8'。」 
with open("a.txt", "r", encoding="utf-8") as f:
    text = f.read()

with open("b.txt", "w", encoding="utf-8") as f:
    f.write("hello")
08JSON 怎么处理？FDE 必用
「字符串转字典用 loads，字典转字符串用 dumps；对文件用 load 和 dump。大模型返回的 JSON 我一定要先剥掉 markdown 代码块再解析，还要包 try/except。」 
import json

obj = json.loads('{"name": "张三"}')     # 字符串 → dict
s = json.dumps(obj, ensure_ascii=False)    # dict → 字符串

with open("config.json", encoding="utf-8") as f:
    cfg = json.load(f)
09包和环境怎么管理？
「每个项目建一个虚拟环境，依赖写在 requirements.txt 里，换机器 pip install -r 就能还原。这样不会和系统里其他项目打架。」 
python -m venv .venv
# Mac/Linux
source .venv/bin/activate
# Windows
.venv\Scripts\activate

pip install requests pandas
pip freeze > requirements.txt
10常见的报错你能看懂吗？
「一般看最后一行就知道类型，再看倒数第二行定位是哪一行。」
报错意思怎么修
KeyError字典里没这个 key用 .get(k, 默认值)
IndexError列表下标越界检查长度 / 边界
TypeError类型不对打印 type() 看实际类型
AttributeError对象没这个属性/方法常见于 None 调方法
ModuleNotFoundError没装这个库pip install 包名
11*args 和 **kwargs 是什么？
「都是让函数接收任意数量的参数。*args 收成元组，**kwargs 收成字典。一般用在写通用函数或包装别人接口的时候。」 
def f(*args, **kwargs):
    print(args)     # (1, 2)
    print(kwargs)   # {'a': 3}

f(1, 2, a=3)
12怎么调用一个 HTTP 接口？FDE 必用
「用 requests，get 或 post，headers 里带鉴权，params 传参数，timeout 一定要设，最后 raise_for_status 检查状态码，再 json() 取数据。」 
import requests

r = requests.get(
    "https://api.example.com/query",
    headers={"Authorization": "Bearer xxx"},
    params={"q": "退货政策"},
    timeout=10,
)
r.raise_for_status()
data = r.json()
print(data.get("answer"))

3. 6 段必背代码能讲出思路就够，不用真背每个字

① 调用大模型 API（最高频）

import os
from openai import OpenAI

client = OpenAI(
    api_key=os.getenv("DASHSCOPE_API_KEY"),
    base_url="https://dashscope.aliyuncs.com/compatible-mode/v1",
)

resp = client.chat.completions.create(
    model="qwen-plus",
    messages=[
        {"role": "system", "content": "你是简洁的客服助手"},
        {"role": "user", "content": "能退货吗？"},
    ],
    temperature=0.3,
)
print(resp.choices[0].message.content)
讲解要点：key 放环境变量不写死；system 定角色、user 是问题；temperature 调低更稳定；取 choices[0]。

③ 对接客户接口 + 异常处理

import requests

def ask(question):
    try:
        r = requests.post(
            "https://客户域名/api/chat",
            json={"question": question},
            headers={"Authorization": "Bearer xxx"},
            timeout=15,
        )
        r.raise_for_status()
        return r.json().get("answer", "未返回答案")
    except requests.exceptions.Timeout:
        return "接口超时，请稍后再试"
    except requests.exceptions.RequestException as e:
        return f"调用失败: {e}"

4. 3 道读代码题比让你写代码的概率高得多

题 1：下面输出什么？
def f(x, box=[]):
    box.append(x)
    return box

print(f(1))   # ?
print(f(2))   # ?
答：[1] 然后 [1, 2]。因为默认参数只在定义时创建一次，两次调用共用同一个 list。
题 2：a 最后是什么？
a = [1, 2, 3]
b = a
b.append(4)
print(a)   # ?
答：[1, 2, 3, 4]。b = a 是引用，两个变量指向同一个列表。
题 3：输出什么？
print([i * i for i in range(4) if i % 2 == 0])
答：[0, 4]。range(4) 是 0,1,2,3，取偶数 0 和 2，平方得 0 和 4。

5. 5 个八股 · 眼熟即可低概率，别花太多时间

装饰器是什么？低概率
「在不改原函数的情况下，给它加功能，比如打日志、计时。本质是把函数当参数传进去，返回一个新函数。」
生成器 / yield？低概率
「用 yield 一次吐一个值，不一次性把数据全放内存，适合处理大文件或大批量数据。」
类和对象？低概率
「class 定义一类东西，__init__ 是初始化，self 指实例自己。实际写脚本用得不多，看代码能看懂就行。」
GIL 是什么？低概率
「Python 的全局锁，同一时刻只有一个线程在执行 Python 代码。所以 CPU 密集的活要用多进程，IO 密集的（比如调接口）多线程还有用。」
怎么提升 Python 运行速度？低概率
「先找瓶颈（别瞎优化）：用向量化代替循环、批量处理、加缓存、IO 密集用并发。真到极限就换更快的库或语言。」

6. 被问住怎么救场这三句比硬答有用

「这个语法我平时用得少，我说下我的思路——应该是先读数据、再处理、最后输出，具体写法我需要查一下文档。」 「这个 API 的具体名字我记不准，但流程是清楚的：拿到 key、拼请求、发出去、解析返回。」 「这块我没深入做过，但代码我能看懂。给我半天时间加文档，我能上手改。」
千万别做：沉默硬编、瞎猜 API 名字、把不知道说成知道。面试官一追问就全塌，反而前功尽弃。

7. 3 小时急救计划照着做，今晚能睡

时间做什么验收标准
0–25 分装好 Python，手敲「调大模型 API」那段，跑通屏幕上能打出模型回答
25–55 分基础 1–6：list/dict、推导式、字符串、默认参数、拷贝、异常能不看答案说出默认参数那个坑
55–85 分JSON + 文件 + pandas 读表统计能说清 loads/dumps 区别
85–110 分requests 对接接口 + 异常处理能讲出 timeout、raise_for_status 为什么加
110–140 分读代码 3 题 + 八股扫一眼3 题都能说出答案和原因
140–180 分背「水平定位话术」+ 救场三句 + 自己讲一遍录音听一遍，不卡壳
如果只有 60 分钟：只做两件事——跑通调 API 那段代码；背熟第 1 节的水平定位话术。这两样能覆盖 80% 的实际场景。

8. 面试官真正想听什么理解这个，比多背 10 道题有用

他问 Python，其实在确认三件事：

  1. 你能不能改脚本——客户现场要临时处理个 Excel、对个接口，你能不能搞定。→ 用六段代码证明。
  2. 你懂不懂 AI 应用的工程常识——key 不能写死、要加超时、JSON 会解析失败、上下文有长度限制。→ 讲这些细节比讲语法分高。
  3. 你会不会瞎承诺——FDE 最怕答应客户「这个能做」结果做不出来。→ 诚实分级正好是加分项。
最后一句话记住：这个岗位要的不是「Python 工程师」，是「能用 Python 把客户的事办成的人」。你只要证明自己看得懂、改得动、不忽悠，就赢了。
